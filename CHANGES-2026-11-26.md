# Read the Paper site — changes, November 26, 2026

Applied from an outside review of the site. The big one: **the app now lives on
this domain.** No more sending people to muse.ai to run it.

## What shipped

- **`app.html` added — the app is self-hosted.** Byte-identical copy of the
  current live app build (artifact v27, the build served at the old muse.ai
  link; sha256 `28e246745e6119b1…`). It runs standalone: its script and styles
  are inline and it keeps its state in the browser's local storage.
  `assets/manifest.webmanifest` came with it so the app's manifest link
  resolves here too.
- **Every "Try Read the Paper" link now points to `app.html`** — top nav, hero
  button, test box, footer. Same site, same domain, no silent trip to a third
  party, and the privacy claim ("no third-party services") is now literally
  true of where the app is served from.
- **Airplane-mode test promoted.** It's now the first block under the hero —
  "Prove it yourself / The airplane-mode test" with the three steps and the
  button — instead of a section near the bottom. The old lower test box was
  removed so the page doesn't say it twice.
- **Demo above the fold.** A three-column breakdown ("What the paper says /
  In plain English / What to watch") of the late-fee clause from the app's
  built-in sample bill — City Power & Water, "J. Sample," 12 Example Street.
  Fully fictional sample only, same as inside the app. No real documents, no
  real bills, nothing personal.
- **Price stated plainly.** Under the hero buttons: free while it's in
  testing; the Founding offer and Case Pass come at launch. No prices
  invented — the Case Pass price is still undecided.
- **Privacy policy moved to its own page: `privacy.html`.** Linked from the
  nav and footer. The old `/#privacy` address still works — the landing page
  redirects it to `privacy.html` — so the Play Store listing and any old
  links don't break. Policy wording itself unchanged.
- **A human on the page.** New "Who built this" block: Nate, Cleveland,
  Tennessee, and the one-line why (a notice showed up in micro print he
  couldn't read; he got tired of signing things he didn't understand).

## Not done (Nate's calls, not build steps)

- **Real domain.** The address is still `canabus.github.io/Read-The-Paper-/`
  with the trailing hyphen. A real domain is ~$12 and is also what the
  Android app (TWA / assetlinks.json) will want. Money decision — left for
  Nate.
- **"If an 11-year-old can figure it out, so can you"** (footer) is still an
  untested claim. It was neither softened nor asserted. It needs a real test
  — hand the app to an actual kid or a non-technical adult and watch step
  one — before it's leaned on anywhere else.
